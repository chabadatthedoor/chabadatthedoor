# Chabad Mitzvah Campaign Management Platform

Internal full-stack SaaS-style app for campaign operations.

## Run

```bash
npm install
npm start
```

Then open `http://localhost:3000`.

Default seeded account:

- member/admin login: `admin` / `admin123`

To use Google-style admin login, create an admin user with an email username first in Admin panel and use that email on **Admin Login**.
